A travel poster for Velmara, the Low Sun Isles — a place that does not exist, where islands float above a calm lagoon and waterfalls pour into the sea beneath a low amber sun. Rendered procedurally in pure-stdlib Python: a violet-to-gold sunset sky, a glowing low sun, floating-island silhouettes with a stone watch-spire, sun glitter on the water, and the place name set in a hand-drawn bitmap face.

## Run it

```sh
python3 main.py
```
